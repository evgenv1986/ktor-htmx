Действие:          completeStep(taskId, roundId, stepId, actualReps)
Инварианты:        session.status == IN_PROGRESS
task.status == IN_PROGRESS
round.status == IN_PROGRESS
step.status == PLANNED
actualReps >= 0
нельзя завершить шаг из неактивной ветки

step.actualReps: null → ActualReps(value)
