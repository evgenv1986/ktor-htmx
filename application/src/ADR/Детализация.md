Подготовить тренировку по плану: Prepare workout session by plan
    план тренировки должен существовать
    план должен содержать упражнение/я (не нулевое количество)

Начать тренировку
    начать можно тренировку которая в статусе подготовлена
    начать можно тренировку которая содержит упражнения
    начать тренировку можно если тренировка содержит не выполненные задания

Начать следующее задание
    начать следующее можно задание если тренировка содержит не выполненные задания

Завершить подход
    завершить подход можно если он в состоянии ожидает выполнения

Завершить задачу
    завершить задачу можно если выполнены все задания в ней
    завершить задачу можно с помощью действия отмены задания

Отменить задачу
    можно если задача в состоянии ожидания или в работе
